# Automatic Guest workflow — intentional DOM change

User explicitly requested complete removal of the numbered stepper. Removed stepNavHome, stepNavCapture and stepNavResult from the modular frontend and removed their controller updates. These are the only exceptions to the original DOM-ID preservation assertion. All 80 legacy methods, remaining IDs, compositor algorithms and the original/legacy HTML are retained. Existing capture/result/retake/confirmation services are reused; guestWorkflowActive/guestStarting and syncGuestWorkflowUI control automatic presentation. [Verification](GUEST_AUTOMATIC_WORKFLOW.md).

# Phase 6 mapping addition

The 80 legacy methods keep their existing mapped modules and callable facade names (Node verification). Existing home/capture/editor/QR/print methods are reused; no new Frame Editor. Added facade functions in `frontend/src/features/home/kiosk.js`: initializeKioskUI, syncSetupLayout, syncKioskStatus, renderRecentPhotos, confirmNewGuestSession and confirmResetShots. `frontend/src/services/booth-access.js` supplies boothFetch and initializeBoothAccess; these are service imports rather than legacy replacements. Existing startNewGuestSession resets private editor/QR state before Setup. See [event checklist](EVENT_DAY_CHECKLIST.md) for behavior evidence.

# FUNCTION_INVENTORY — Phase 0 / Phase 1

## Bổ sung Phase 3

`generateQRCodeForCurrentPhoto` nay gọi owner finalize sau complete, không upload ảnh. `scheduleQRCodeUpdate` chỉ cập nhật visibility/cached QR khi editor dirty, không gửi request/tạo token. `renderQRCodeVisual` giữ DOM cũ nhưng đọc local backend PNG. `copyQRLink` giữ URL riêng. External upload implementation chuyển archive `legacy/qr-upload.phase1.js`, không import/chạy trong frontend. `confirmAndSaveSession` thêm complete → finalize, lỗi QR giữ file đã lưu và cho thử lại. Các ghi chú legacy upload opt-in ở bảng Phase 1 bên dưới là lịch sử, đã bị retire trong Phase 3.

## Bổ sung Phase 2

Mapping 80 method gốc bên dưới vẫn giữ; các method capture/retake nay chờ backend ACK qua `services/photo-repository.js`. Không đổi compositor/layout/filter/sticker algorithms.

| Điểm cũ | Tích hợp mới |
|---|---|
| startAutomaticSession / startOrContinueSequence | prepareSession → ensureSession → POST /api/sessions; create key/token giữ ổn định khi retry |

## Callback và DOM coverage

`SOURCE_AUDIT.json` liệt kê 68 inline handlers (cả static markup và template string động), DOM IDs/classes, state properties, CDN paths, callback registrations kèm dòng nguồn. `function-map.json` chứa call sites và toàn bộ `this.*` dependencies của từng method. Callback closures di chuyển cùng method, không tạo logic thứ hai.

- `DOMContentLoaded → app.init()`: thay bằng module bootstrap sau khi DOM parse xong.
- `window.app`: facade tạm thời được đăng ký trong `core/events.js`; giữ các inline `onclick/onchange/oninput` và dynamic templates. Chưa chuyển hết sang event delegation.
- `renderSimFrame`, `tick`, FileReader/Image onload, Promise/array callbacks: nằm trong module của method cha.
- `getNormalizedPos`, `onPointerDown/Move/Up`, mouse/touch listeners: `features/editor/canvas-interactions.js`.
- Timers countdown/grace/start/next/auto-print/QR: IDs trong store, cleanup ở utils/timing.js.
- Toast timeout chỉ gỡ DOM toast; giữ nguyên. `pagehide` dọn timers/streams.

## Screen / media / controls

Home `screenHome`: camera selector/mirror, frame presets/upload, timer 3/5/7/10. Capture `screenCapture`: `liveVideo`, `simLiveCanvas`, countdown/grace overlays, dynamic 6 slots, retake/delete/reset. Result `screenResult`: `compositeCanvas`, filters/stickers/color/text, QR status, print/download. Settings và mobile preview giữ nguyên IDs; calibrator inputs được bổ sung. `printArea/printImageElement`, flash và toast vẫn dùng CSS/DOM gốc.

State đầy đủ nằm trong SOURCE_AUDIT; filters được chuyển config/filters.js, các field khác ở store.js. layouts.js chuẩn bị metadata 4/6 ảnh; UI/thuật toán legacy vẫn 6 ảnh. State machine và API lưu trữ thuộc Phase 2, chưa tạo file rỗng.
